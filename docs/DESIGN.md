# 디자인 규칙

이 블로그에 적용한 디자인 규칙이다. 크림색 종이 위에 인쇄한 잡지 같은 느낌을 목표로 한다.

- 참고한 스타일: [Refero — Telescope](https://styles.refero.design/style/e6fb72b4-877d-46ab-8f94-590b971d4dc1). 원문은 저작권 때문에 레포에 넣지 않는다 (로컬 전용 `docs/DESIGN.reference.local.md`).
- 토큰 정의: `app/globals.css`. 컴포넌트는 역할 이름(`background`, `foreground` 등)만 쓴다.
- 결정 이유: `docs/PROGRESS.md` "결정 기록"

## 원칙

- 평평하게 만든다. 그림자를 쓰지 않고, 깊이는 바탕색과 흰 면의 차이로만 낸다.
- 모든 모서리는 2px. 둥근 알약 모양 버튼이나 원형 이미지는 쓰지 않는다.
- 강조색은 한 곳에만 쓴다. 여러 곳에 쓰면 강조가 아니게 된다.
- 위계는 굵기가 아니라 크기와 자간으로 만든다.
- 이미지에는 테두리나 배경을 넣지 않는다.

## 색상

라이트 테마만 쓴다.

| 역할 | 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- | --- |
| 바탕 | `background` | `#f4f3f0` | 페이지 전체 |
| 글자·선 | `foreground`, `border` | `#1a1915` | 본문, 제목, 구분선. 순수한 검정(`#000`)은 쓰지 않는다 |
| 보조 글자 | `muted-foreground` | `#686c73` | 날짜, 설명, 라벨. 본문에는 쓰지 않는다 |
| 면 | `surface` | `#ffffff` | 헤더, 카드, 태그, 목차 박스 |
| 강조 | `highlight` | `#e3f794` | 현재 메뉴의 배경에만. 글자색·hover·태그에는 쓰지 않는다 |

- 보조 글자색은 참고 스타일의 `#82868e`보다 진하게 했다. 바탕 대비 4.75:1, 흰 면 대비 5.27:1로 WCAG AA(4.5:1)를 맞춘다.
- 링크 hover는 색 대신 밑줄로 표시한다.

## 글자

폰트는 Pretendard 하나. 굵기는 400(글 본문 안 `strong`만 굵게).

| 토큰 | 크기 | 행간 | 자간 | 쓰는 곳 |
| --- | --- | --- | --- | --- |
| `caption` | 12px | 1.1 | +0.36px | 메뉴(대문자), 날짜, 태그, 라벨 |
| `body-sm` | 19px | 1.6 | -0.13px | 본문, 설명 (글 본문은 행간 1.75) |
| `body` | 23px | 1.35 | -0.16px | 목록 제목, 섹션 제목, 글 요약 |
| `heading` | 55px | 1.15 | -0.94px | 글·프로젝트 제목 |
| `heading-lg` | 57px | 1.15 | -1.14px | 페이지 제목, 홈 소개 |

- 행간은 한글이 여러 줄일 때 답답하지 않게 참고 스타일(1.05~1.15)보다 넓혔다.
- 모바일(640px 미만)에서는 제목 36px, 글 요약 19px.

## 간격

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `section` | 56px | 큰 섹션 사이 |
| `card` | 14px | 카드·박스 안쪽 여백 |
| `element` | 10px | 작은 요소 사이 |

Tailwind 기본 숫자 눈금(`p-6` = 24px)을 덮어쓰지 않도록 숫자 이름 토큰은 만들지 않는다.

## 구성 요소

- **헤더**: 화면 위에 고정. 흰 면, 아래 2px 검정 선. 왼쪽 로고, 오른쪽 메뉴와 GitHub 아이콘(새 탭).
- **현재 메뉴**: 강조색 배경, 검정 글자, 2px 모서리.
- **목록**: 항목 사이 1px 검정 선. 제목 `body`, 설명 `body-sm` 보조색, 날짜 `caption`.
- **카드**(프로젝트, 시리즈 표시, 이전/다음 편): 흰 면, 1px 검정 테두리, 안쪽 여백 `card`.
- **태그·기술 스택**: `caption` 크기, 2px 모서리.
- **목차**: 지금 읽는 섹션만 검정 글자와 왼쪽 2px 검정 선.
- **맨 위로 버튼**: 글 상세에서 600px 넘게 내려가면 오른쪽 아래에 나타난다. 흰 면, 검정 테두리, `TOP ↑`.
- **코드 블록**: 검정 바탕에 크림색 글자.
